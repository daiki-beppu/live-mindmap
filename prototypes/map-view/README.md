# PROTOTYPE — マップの見せ方（issue #7）

捨てる前提の試作。差分更新エンジンのラン結果（issue #6）を時間順に再生し、3 つの描画ライブラリで同じマップを見比べる。

```sh
bun install
bun run dev   # ラン結果を public/data に書き出してから vite を起動
```

http://localhost:5178/?variant=A を開く。`←` / `→` で案を切り替え、`Space` で再生・停止、`,` / `.` で前後の変化へ飛ぶ。

| 案 | ライブラリ | 描き方 |
|---|---|---|
| A | React Flow | 種別の色帯つきカード。配置は自前の左→右の木レイアウト。位置の変化は CSS transition |
| B | markmap | 線の上に文字を置く古典的なマインドマップ。d3 の transition（ノードのキーを id に差し替えて使う） |
| C | Plait（Drawnix） | マインドマップ編集器のボードに木を丸ごと渡し直す |
| D | React Flow | A の仕組みのまま見た目を C に寄せたもの（角丸の淡い塗り・種別色の曲線の枝・バッジなし）。高さは描画後の実寸で配置し直す |
