# エクスポートの公開

[エクスポートの公開](../../GLOSSARY.md)（会議の後にエクスポートを利用者の Cloudflare アカウントへ期限つきで置き、URL で見せること）の仕様・実装・見直しをするときに読む文書。何を外に出すか、見る相手をどう絞るか、確認をどこで挟むか、置いた物をどう片付けるかの判断の基準と、はまりどころを書く。決定そのものは仕様 [#1246](https://github.com/daiki-beppu/live-mindmap/issues/1246) と地図 [#1206](https://github.com/daiki-beppu/live-mindmap/issues/1206) にある。

- 用語: [エクスポートの公開・合言葉・取り下げ・閲覧の共有](../../GLOSSARY.md)
- ADR: [0018 ホスティングは Cloudflare と Alchemy、今はしない](../adr/0018-host-on-cloudflare-with-alchemy-not-now.md)（server のホスティングだけを指し、エクスポートの公開は対象外）、[0017 重い依存は管理ディレクトリへ](../adr/0017-heavy-deps-in-managed-dir-cli-stops-at-check.md)

## 外に出す物は、ファイルの名前や画面ではなく、HTML に埋め込んだデータで数える

`map.html` は、`log.jsonl` の出来事を丸ごと JSON にして HTML に埋め込み、見返しの画面はそれを再生して組み上がる。字幕を画面に出さないようにしても、発言の文字はソースに残る。手で Cloudflare Pages に出した `map.html` には、発言の行が 1,100 件入っていた。録音入りの `map-audio.html` を外しただけで、登壇者の話の文字起こしはそのまま出ていた。

「マップだけ」の版で抜くのは、`remark` の文字と、`screen` の `lines`（共有画面から読んだ文字）。`start` の会議名は、URL・`<title>`・プレビュー用のメタに出さない。マップの復元は `remark` も読むので、抜いた列でも見返しが同じに組み上がるかを、復元のテストで確かめる（[#1249](https://github.com/daiki-beppu/live-mindmap/issues/1249)）。

## 見る相手は置き場ではなく中身で絞る。合言葉は製品が作り、利用者には選ばせない

置き場で絞る方法（Cloudflare Access のメールの PIN）は、Zero Trust の組織を作るための支払い情報の入力と、OTP の設定を利用者の宿題にする。中身で絞れば、置き場は Workers Admin 1 つの権限のただのファイル置き場で済み、置いた中身は Cloudflare からも読めない。

暗号化した HTML は URL を知れば誰でも取れ、手元で好きなだけ合言葉を試せる。置き場で回数を制限する仕組みは働かない。そのため、守りは合言葉の強さと鍵の導出の重さだけになる。`--passphrase` を持たないのはこのためで、シェルの履歴に残ることも理由の 1 つ。

## 「指定が無ければ止まる」を閲覧の共有から持ち込まない。止まる理由は、製品が値を決められないこと

閲覧の共有が絞る相手の指定なしで止まるのは、許すメールアドレスを利用者しか決められないからだ。合言葉は製品が作れるので、エクスポートの公開は止まらずに合言葉を作って置く。同じように、閲覧の共有の「アカウントを前提にしない」も持ち込めなかった。アカウント無しの一時の置き場は 60 分・5 MiB までで、使い物にならない（[#1207](https://github.com/daiki-beppu/live-mindmap/issues/1207)）。閲覧の共有の方針を持ち込むときは、その方針が何を理由にしているかまで読む。

## URL を開く人だけでなく、URL を取りに来るボットに何が見えるかも数える

Discord は貼られた URL を取りに行き、タイトルや画像をプレビューに出す。プレビューは、URL を開かない人や、チャンネルの外にも届く。`<title>` とプレビュー用のメタは、合言葉でも `--anyone` でも決まった文にする。プレビューに中身が出ないので、AI の拒否（robots.txt・`x-robots-tag`・UA での 403）からは Discordbot などのプレビュー用のボットを外してよい。弾くと、リンクを貼ったときに壊れて見える。

## CLI の出力を読むのはエージェント。確認は、置いた後の注意文ではなく、置く前に止めて聞かせる

`cli` は利用者がエージェントに頼んで叩かせる前提で作ってあり、出力は利用者に届かない。発言の文字・録音を含む公開は、Cloudflare に何も送らずに終了コード 4 で止まる。そして、何を利用者に聞くか（閉じた会議なら相手の了解、イベントなら規約と登壇者の許可）をエージェント向けに出し、`--confirmed` で実行し直させる。依存の導入の exit 3（`exitCodeTeardown`）と同じ形。

この形でも、エージェントが聞かずに最初から `--confirmed` を付けることは防げない。仕様にもそう書いてある。この仕組みが同意を担保していると読まない。

## 製品が確かめられない値は、聞きも記録もしない

会議の種類（社内・社外・公開のイベント）は聞かない。指定させても製品は真偽を確かめられず、手間だけが増える。同意も記録しない。記録すると、製品が同意を取った証拠に見える。記録するのは、公開した事実（Worker 名・URL・段・合言葉か `--anyone` か・期限・状態）だけ。

## 見えなくするのは 410、消すのは後片付け。消す処理は、資格情報を持つ公開のコマンドに載せる

期限の時刻を Worker に焼き込み、期限の後は 410 を返す（`assets.run_worker_first: true` が要る）。誰も何も流さなくても、期限で見えなくなる。置き場から消すのは、公開・一覧・取り下げの最初に行う後片付けで、失敗しても本来のコマンドは止めない。410 があるので急がない。

掃除用の Worker と Cron は置かない。Worker に消させるには、API トークンを Worker の secret に置くことになり、アカウントに常駐の物も増える。どの `cli` のコマンドでも消す形も取らない。`start` などが、ネットワークと Cloudflare の資格情報に依存してしまう。

期限には上限（30 日）を置き、無期限は許さない。無期限は、410 を焼き込む仕組みと、「期限つき」という用語の定義の両方を壊す。

## 置き場の Worker は、必ず公開中の記録を持つ。記録は 1 か所に置き、消しても行を残す

後片付け・取り下げ・置く途中の失敗は、どれも「置き場の Worker には公開中の記録がある」という 1 つの性質を守る操作だ。形式仕様（#1246 の Formal Spec のコメント）では、これを 1 つの不変条件で確かめた。置く途中の失敗で作りかけを残す mutant も、この性質で red になる。

- **記録の置き場所**: セッションをまたぐ 1 か所（`~/.live-mindmap/` の下）に置く。セッションのフォルダに置くと、利用者がフォルダを消したときに、置いた物を消す手がかりもなくなる
- **消した後の行**: 消しても行は消さず、状態（公開中・期限切れで消した・取り下げた）を変えて残す
- **記録に無い `lmm-` の Worker**: 一覧で知らせるだけにする。期限が分からないので、製品が消してよいかを判断できないから。消すのは、エージェントが利用者に確かめてから取り下げで名指しする

## 置き方は Direct Upload を `HttpClient` で叩く。Alchemy は使えるようになるまで入れない

Workers Static Assets は、REST API の Direct Upload（assets-upload-session → assets/upload → script PUT）だけで置け、wrangler（180 MB 超）は要らない。Alchemy v2 で置くこともできるが、次の理由で、HTML 1 枚と数行の Worker には見合わない（[#1218](https://github.com/daiki-beppu/live-mindmap/issues/1218)）。

- `node_modules` が約 1.4 GB になる
- 管理ディレクトリに別の版の `effect` が入る
- beta の破壊的変更が続いている
- ライブラリとしての呼び方が文書に無い

外への通信は、このリポジトリの慣習どおり Effect の `HttpClient` で書く。テストでは偽の client に差し替えられる。

## 隣の置き場（Drive・Cloudflare OS）は、決めた制約で照らすと公開を兼ねられない

置き場を足す案が出たら、期限・合言葉（置き場から読めない）・AI の拒否・プレビューの制御の 4 つで照らす。

- **Google Drive の共有リンク**（[#1232](https://github.com/daiki-beppu/live-mindmap/issues/1232)）: 「リンクを知る全員」に期限をかけられず、Google から中身が読める
- **Cloudflare OS**（[#1214](https://github.com/daiki-beppu/live-mindmap/issues/1214)）: 外から置く API が無く、期限も無い。売りの権限の仕組みは、Cloudflare OS の接続を通して読んだデータにしか効かない

どちらも保管や社内の共有としては別に扱い、エクスポートの公開とは混ぜない。資格情報の置き場所だけは、エクスポートの公開にそろえる。
