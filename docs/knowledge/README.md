# 知識文書

用語（[GLOSSARY.md](../../GLOSSARY.md)）にも判断（[docs/adr/](../adr/)）にもならない、その領域で作業するときの判断の基準・はまりどころ・確かめ方・実測した数字を、触る領域ごとに置く。時系列の経緯は [開発ログ](../devlog/) と PR にある。

- [エクスポートの公開](export-publish.md): 会議の後にエクスポートを期限つきで外に置く機能の仕様・実装・見直し
- [右の列](side-panel.md): 根拠・TODO・変わったことの段を足す・変える・テストするとき
- [セッションの sink](session-sink.md): server のセッションの sink と、語彙・発言の流れ・録画の feed・再生の補正を触るとき
- [取り込みの試行](intake-attempts.md): ヘルパーの起動・起動し直し・停止・試行中の指令（`intakeAttempts`）と、それを呼ぶ `Sessions` の配線を触るとき
- [更新の計画](update-plan.md): 差分更新のモデルと判定のモデルの選び方（`updatePlan`）と、それを呼ぶ CLI と server の配線を触るとき
- [CLI と server の受け渡し](server-protocol.md): CLI と server の間の経路・本文・応答（`serverProtocol`）と、web が送る本文を触るとき
- [差分更新の問い合わせの続き](diff-continuation.md): 直前の応答・送り直す共有画面と、それを持つ core・Claude の adapter・振り分け・復元を触るとき
- [途中結果から発言を作る段](remark-settling.md): 確定の段（`settle`）と出す直前の関所（`remarkGate`）、特に本文どうしの比べ方を触るとき
- [セッションの開始とブラウザへの送り口](session-start-and-viewers.md): `Sessions` の開始の括弧・状態の門番と、`Viewers` の送り口・frame の種類ごとの表を触るとき
- [過去のセッションのフォルダの読み側](session-folder-reading.md): `log.jsonl` などを読む CLI のコマンドや bench を足す・変えるとき、壊れた行の失敗の文を触るとき
- [話者の名前の包み](speaker-names.md): 話者の名前を持つ・出す処理（`openLogged` の `nameSpeaker`）と、それを通るライブ・再生・評価・bench を触るとき、名前の推定のプロンプトを変えて前後を比べるとき
- [takt の run](takt-runs.md): takt で実装させるとき、run の報告を読むとき
- [README の 2 つの版](readme-versions.md): 英語の `README.md` と日本語の `README.ja.md` を直すとき、ファイルを移す PR をマージするとき
