# 補足はノードの種別にし、添える先の発言を根拠に持たせ、出どころで会議の外の知識を見分ける

[補足](../../GLOSSARY.md)（会議で出そうな質問に、聞かれる前に AI が答えておくもの）を、マップのノードの種別の 1 つにする（地図 [#1733](https://github.com/daiki-beppu/live-mindmap/issues/1733)、決定 [#1739](https://github.com/daiki-beppu/live-mindmap/issues/1739)）。補足は添える先のノードの子として木に置き、差分操作・ログ・スナップショット・エクスポート（JSON・Markdown・`map.html`・エクスポートの公開）に、ほかのノードと同じく載る。種別の名前はエクスポートで外に出る。

[#1734](https://github.com/daiki-beppu/live-mindmap/issues/1734) は、会議の外の知識の補足を「ノードにせず、マップのデータの外に置く」と仮決めした。[#1738](https://github.com/daiki-beppu/live-mindmap/issues/1738) の試作を見た利用者は、ノードの種別にする案を選んだ。この ADR は #1734 の仮決めを置き換える。そのうえで、「ノードは根拠となる発言を 1 つ以上持つ」と「話されなかった共有画面の中身はマップに出ない」の約束は崩さない。

- **根拠は、補足が答える話の出てきた発言**。用語の説明なら、その用語が言われた発言を指す。話されなかったことには根拠が無いので、補足は付けられない。補足が「話されたことにだけ添える」は、約束ではなく形で成り立つ
- **出どころとして `会議の中` か `会議の外` を持つ**。`会議の外` の補足は、根拠の発言を持っていても、中身がその発言から来ていない。画面とエクスポートでは、この 2 つを見分けられるように見せる
- **補足は子を持たず、削除の「子を持たない」には数えない**。誤認識のノードを消すとき、そこに添えた補足も一緒に消える

## Considered Options

- **マップのデータの外に置き、画面だけで添える（#1734 の仮決め）**: 木の約束には触れないが、試作では木の中に見える案 A が選ばれた。残すにも書き出すにも、マップの外に別の記録を足すことになる
- **根拠の発言を持たないノードを認める**: 「ノードは根拠を 1 つ以上持つ」が崩れ、反映・エクスポート・評価が根拠の無いノードを扱うことになる。話されなかったものに付かないことも、形では守れなくなる
- **会議の中から分かる補足だけをノードにし、会議の外の知識は別の扱いにする**: 2 つが同じ「詰まる場面」に答えるのに、置き場所と記録が 2 つに分かれる

## Consequences

- ログに補足のノードが入る。補足の種別を後から外すと、それを含むログとエクスポートの読み方が残る
- 補足は差分更新とは別の呼び出しで作る（#1737）。その結果も、ライブ・復元・計測が同じ反映を通るように、ログの行として書いて畳む（[ADR 0024](0024-reflect-diff-row-in-one-pure-fold.md)）
- 補足は根拠を持つので、根拠の段にも出る。`会議の外` の補足の根拠を「中身の出どころ」と読ませない見せ方が要る
