## 関係づけ更新後のnoop（問題1606-1）

古い議題Aを畳み、議題Bとその案を表示した同じ会議ページで、A配下の関係づけを追加・付け替え・解除し、各更新の後に成功したnoopを反映した。Snapshotは共通復元処理で生成し、ブラウザのWebSocket受信経路へ渡した。これは上記CLI・HTTPを通した確認とは別のブラウザheavyテストである。

修正前は、最初のnoopを処理した後にA配下の案が現れ、表示IDが `[root,n1,n3,n4]` から `[root,n1,n2,n3,n4]` に変わった。修正後は各noop後も4ノードを維持し、表示中の全ノードの矩形、カメラ、字幕矩形が各更新前と一致した。各noopの後に人がAを開き、最新の軸名（解除時は空）を確認して閉じている。人の操作ではカメラが変わるため、各更新の直前を比較基準とした。
