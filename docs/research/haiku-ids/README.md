# 差分更新の変更に、捨てた操作と仮 id の対応を載せて cli eval にかける（issue #686）

2026-10-09〜10 に 16GB の M4 で計測した。使い捨てのブランチで、main には入れない。

## 条件

- コードは main（`1cc8a25`）に、評価用のパッチ（[eval-only.patch](eval-only.patch)）を当てた。#655 のパッチに、次を足したもの:
  - `applyOps` が仮 id → n の id の対応（`refs`）も返す。セッションは前回の応答の `dropped` と `refs` を持ち、次の `DiffInput` に `lastApplied` として渡す（失敗した回の後は渡さない）
  - `LM_EVAL_IDS` で、変更（`renderChanges`）に何を載せるかを選ぶ。`refs`: 「追加」の行の末尾に「（前回の応答の仮 id u2）」を添える。`drops`: 変更の末尾に「### 前回の応答で捨てた操作」として、捨てた操作の JSON と理由を 1 行ずつ載せる。`both`: 両方
  - query を開き直した最初のメッセージ（マップの全体を送る回）には、どちらも載せない
- Haiku 5.5 は low、SYSTEM の末尾に [append-decision.md](append-decision.md)（#655 の v2 の「決定を TODO で置き換えない」の部分だけ）を足した。Sonnet 5.5 は medium、追記なし
- 比べる値: screen は #655 で main の上で取った Sonnet 5.5 medium の 2 本。facilitators は今回 main（`LM_EVAL_IDS` なし）で取り直した Sonnet 5.5 medium の 2 本
- 素材は `synth/screen`・`synth/facilitators`。認証は Claude Code のサブスク（`env -u ANTHROPIC_API_KEY`）。流し方は [run.sh](run.sh)、2 本ずつ並べて流した。料金・遅れは [cost.mjs](cost.mjs)、等速の遅れは [lagReal.mjs](lagReal.mjs)、外れの分類は [miss.mjs](miss.mjs)、捨てた操作の分類は [drops.mjs](drops.mjs)
- 基準（#615）: 2 素材×2 本で、Sonnet 5.5 から差は 1 件まで。等速の screen の p90 は 12 秒以内

## 分かったこと

1. **Haiku 5.5 low は、screen と遅れでは基準に届いたが、facilitators の決定で届かなかった。** screen は決定 7・TODO 12 で Sonnet（6・12）と並び、等速の p90 は 10.9 秒（基準 12 秒）。facilitators は決定 3 対 5 で、差が 2 件
2. **facilitators で Haiku が落とした決定は、id の誤りではない。** 捨てた操作は各 1 件だけ。「今日は打ち手の方向性まで出し、具体的な中身は詰めない」「振り返りの半日を計画に入れられない案件は、ひきだしの記事の対象にしない」を、2 本とも決定として拾っていない（Sonnet も後者は 2 本とも、前者は 1 本で落とす）
3. **Sonnet では、仮 id の対応（refs）だけで、親が無くて捨てる操作が 0 になる。** both・refs の 3 本の screen と both の facilitators 1 本で 0、facilitators のもう 1 本で 2（うち仮 id 1）。品質は main と同じか 1 件多く、遅れ・料金も変わらない。drops だけでは 4 件残った
4. **Haiku は対応を見せても、直前の応答の仮 id を親に書く。** both でも 4〜10 件残る。ただし捨てた操作を見せると、次の応答で add し直すので連鎖しない（both・drops は 1〜2 回で途切れる）。refs だけでは連鎖が残り（2,3,2,3）、15 件と一番多い
5. **Haiku は both で遅くなった。** thinking が 25〜35k → 39〜45k、構造化出力のやり直し（num_turns 3）が 39 回中 7 回（#655 の v2 では 1 回）。1 回の中央は 9.4〜10.4 秒（待ち時間なし）。等速では 1 発言ずつなので p90 10.9 秒に収まる
6. 料金: Haiku both は 1 会議 $0.075〜0.091（Sonnet の約 1/9〜1/14）
