# 念押し（必ず守る）
## 前の応答で足したノードの id
- 前の応答で add したノードは、「前回からのマップの変更」に「追加 n12 …」の行として、n で始まる id 付きで出る。以後はその n の id で指す。仮 id（ref）はその応答の中でだけ通じ、次の応答では使えない。
- 前の応答で add したのに「追加」の行に出ていないノードは、作られていない（捨てられた）。その仮 id を parent・node に書かない。そのノードがまだ要るなら、今ある親の下に add し直す。

## 決定を TODO で置き換えない
- 合意した内容（「〜してもらう」「〜を絞る」「〜にする」）は、論点の子の決定にする。合意に担当者の作業が付いていても、決定を TODO で済ませない。
- その作業は、決定とは別に TODO として add する。決定と TODO の両方を残す。
