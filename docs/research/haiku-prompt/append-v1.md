# 念押し（必ず守る）
## 仮 id は同じ応答の中だけ
- add の ref に付けた仮 id（"a1" など）は、その応答の中でだけ通じる。次の応答では、もう使えない。
- 前の応答までに add したノードを parent・node・into・from に書くときは、「前回からのマップの変更」の「追加 n12 …」の行に書かれた n で始まる id を使う。前の応答の仮 id を書いた操作は、適用されずに捨てられ、その子の操作も一緒に捨てられる。
- 応答を返す前に、parent・node・into・from に書いた id がすべて、次のどちらかであることを確かめる: 現在のマップ・変更に出てきた id、またはこの応答の中で前に add した仮 id。

## 決定を TODO で置き換えない
- 合意した内容（「〜してもらう」「〜を絞る」「〜にする」）は、論点の子の決定にする。合意に担当者の作業が付いていても、決定を TODO で済ませない。
- その作業は、決定とは別に TODO として add する。決定と TODO の両方を残す。
