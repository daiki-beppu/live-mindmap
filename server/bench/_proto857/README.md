- `prep.mjs`: 問いを 2 種類作る
  - どのノードの話か（`in/node.jsonl`、79 問）: #764 と同じ state・選択肢（ノード一覧＋new・none、選択肢は中央 51 個）。Jev の数え方で 1 回 2.5k〜4.5k トークンの全問と、Claude が何も触らなかった（どのノードにも関係しない）2.5k 未満の全問。関係あり 54・関係なし 25。正解は Claude がその発言で触ったノード（追加なら親）。議題単位は、答えと正解をそれぞれ祖先の議題に読み替えて比べる
  - 役割 8 択（`in/role.jsonl`、150 問）: screen の発言 772 本から等間隔に 150 本。state は直前 2 発言＋判定する発言。8 択は docs/knowledge/2026-09-30.md と同じ（新しい案・課題・問い・決定・TODO・既存の話の補足・進行・雑談）

- `measure.mjs`: 1 問ずつ、選択肢の順を「そのまま」と「逆」で、3 モデルを順に回して呼ぶ（並べて呼ばない。時間帯の差が 3 社に等しく乗る）。手元（日本）から、時間切れ 10 秒。Workers AI の枠切れはそのモデルだけ止め、他の失敗は止める。答えは `out/<model>.jsonl`
- `analyze.mjs`・`paired.mjs`: 集計（本文は出さない）。出力は [results.md](results.md)
- 鍵は `op run --env-file=.env.op --`（`.env.op` はコミットしない）と `CLOUDFLARE_ACCOUNT_ID`。値の場所は地図 #757 の Notes
