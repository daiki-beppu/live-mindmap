# #768 の試作（使い捨て）

「共有画面の画像を判定し、Claude に添えるかを決める」の試作。結論は issue #768 のコメントが正本。main には入れない。

## 作り

- `judge.mjs <clef-flash|clef> <screens.tsv> <out.jsonl> [min=0.3]`: 共有画面の変化を 1 枚ずつ、直前に「添える」とした画面と 2 枚並べて Clef（Workers AI）に渡し、noul「資料の中身が変わったか」を聞く。min 未満なら添えない。共有なし・最初の 1 枚は比べずに添える。失敗したら止める
- 鍵は `op run --env-file=.env.op --`（`CLOUDFLARE_API_TOKEN` と `CLOUDFLARE_ACCOUNT_ID`。`.env.op` はコミットしない。値の場所は地図 #757 の Notes）
- `screen.tsv`: 合成会議 `synth/screen` の slides.tsv（14 回の変化）。`window.tsv`: 10/09 の実会議（Meet、92 分、変化 1,285 回）の 1800〜2280 秒の 159 枚。`try.mjs` は 1 回だけ呼ぶ確認

## 結果（2026-10-12）

- 合成会議: 最初の問いでは、共有が終わって顔だけになる変化を落とした。「資料が消えて顔だけになった・顔だけから資料が出た、も変わった」と足すと、Clef は 14 回すべてを残した（0.91〜0.99）。flash は共有の始まりと終わりを 3 回落とした（`screen.*.v2.jsonl`）
