# #1379 の計測（使い捨て、main には入れない）

「Jev の画像判定を規則 B に重ねると、採る条件を満たすか測る」（#1379、地図 #1371）の計測。結論は issue #1379 のコメントが正本。

- `replay.ts <none|all|gated> <model> <min> [from] [to] [nth]`: 10/09 のログの diff の区切りで、main の `screenSelection.ts` をそのまま通して規則 B を再生し、Jev の判定を重ねる。`none` は #1377 の数（区間 58 枚・全体 451 枚）と一致する
  - 判定は、画面がログに届いた時刻に、その時点で最後に添えた画像と比べる。答えが届く時刻は「届いた時刻 + 測った往復」
  - 差分更新の組み立ての時刻は記録が無いので、最も早く見積もる（screenCount 枚目の画面と新しい発言のうち遅い方）。その時刻までに答えが無ければ今どおり添え、`late` に数える
  - `all` は届いた画面すべて、`gated` は届いた時点で起点 + 10 秒以上の画面と、持ち越しになった画面だけを判定する
  - 1 枚の画像 $0.0044（#927 の数え方）、判定は入力 $42／10 億トークン
- `synth.ts <model> <min> [nth]`: 合成会議 `synth/screen` の 14 回の変化（`screen.tsv`）を、直前に添えた画面と比べて判定する
- `jev.ts`: 呼び出しと答えの貯め置き（`cache.jsonl`。画像のパスと p・ms・トークンだけ）。同じ組の `nth` 回目を聞き直せる
- 問いは #768 の Clef 版と同じ文。鍵は環境変数 `TYPESAFE_AI_API_KEY`
- `window.clef.jsonl` は #768 の試作の Clef の答え（突き合わせ用）。`run-*.jsonl`・`synth-*.jsonl` が結果
